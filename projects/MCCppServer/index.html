1.12.2 C++ Mc Server

A recreation of the 1.12.2 server jar in C++.

Reasoning

The goal of this project is to create a functional minecraft server that 1.12.2 clients can connect to and play on. This is solely being done to see how fast I can get a minecraft server running by using Compiled C++, This is not a replacement for existing servers as its gonna be undenably worse in terms of features and will only ever support 1.12.2.
