## About PanicEngine

PanicEngine is an experimental game engine developed by AkaneDev Labs.

The engine is actively developed, with a focus on exploring game development concepts and building the technology needed to bring unusual ideas to life.

It is still a work in progress, with new features and improvements being developed over time.

## Projects using PanicEngine

### Voidrunner

[Voidrunner](https://akanedevau.itch.io/voidrunner) is the first game built using PanicEngine.

It's a simple vector 3D game running within the engine's 2D environment, serving as a technical demonstration of what PanicEngine can do.

## Development Status

PanicEngine is experimental and actively developed.

Features, behaviour and APIs may change as development continues.

### Access

PanicEngine is currently an internal AkaneDev Labs project. Access is restricted and only available through special invitation.
